# WordPress conversion mapping

The static build intentionally mirrors a future component/template-part architecture and avoids framework lock-in.

| Current section | Suggested WordPress destination | Editable data |
|---|---|---|
| Sticky header | `template-parts/header/site-header.php` | Navigation + WhatsApp CTA |
| Hero | `template-parts/home/hero.php` | Eyebrow, heading, copy, CTA |
| About | `template-parts/home/about.php` | Heading, body, value pills |
| Training | `template-parts/home/training.php` | Repeater: title, description, availability CTA |
| Community | `template-parts/home/community.php` | Copy, feature list, image |
| Testimonials | `template-parts/home/testimonials.php` | Keep disabled until authentic content exists |
| First visit | `template-parts/home/first-visit.php` | Ordered steps |
| Gallery | `template-parts/home/gallery.php` | Media Library image collection |
| Membership CTA | `template-parts/home/membership-cta.php` | Copy + WhatsApp CTA |
| FAQ | `template-parts/home/faq.php` | Repeater: question + verified answer |
| Contact | `template-parts/home/contact.php` | WhatsApp, verified address, message builder |
| Footer | `template-parts/footer/site-footer.php` | Business details, verified social links |

## Gutenberg approach

Keep each section as one top-level block/pattern with simple inner blocks. Avoid deeply nested layout dependencies. Training cards, FAQ items and first-visit steps can use repeatable InnerBlocks or custom block attributes. Gallery should use core Image/Gallery primitives where possible.

## Data migration

The source of truth for repeated static content is `assets/js/content.js`. Migrate those arrays to block attributes, registered post meta, ACF-style fields if intentionally adopted later, or a small theme options model. Do not hard-code unverified operational facts.

## Theme architecture

Retain CSS custom properties for palette, spacing and radii. Enqueue stylesheet and JavaScript through WordPress APIs. Keep JavaScript behavior progressive and independent of markup generated by a page builder.

## Verification gates

Before publishing a WordPress version, re-confirm the WhatsApp number, address, map target, opening hours, packages/prices, personal-coaching availability, social profiles and any testimonials. Never migrate placeholders as if they were verified facts.
